## Final Project Overview

The Capstone Final Project requires implementing an end-to-end distributed Machine Learning pipeline on the modified **NASA Airfoil Self Noise dataset** using Apache Spark, from raw data extraction and ETL cleaning to model training, evaluation, and persistence.
