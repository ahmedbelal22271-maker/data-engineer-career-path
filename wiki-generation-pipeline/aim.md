# Aim — Data Engineering Wiki Processing Pipeline

## About aim.md

This file defines the project's purpose, structure, and processing flow so any AI agent entering this project understands the full picture before taking any action. It prevents the agent from getting lost in details and focusing on the wrong priority.

This file is injected into the initialization prompt (see Initialization Prompt section below) to give every new session context. When editing this file, the metadata in the Initialization Prompt section must be updated to match.

## Purpose

A processing pipeline that receives an updates file (`updates.txt` in the project root, or any file placed in `updates/`) containing new data engineering source material, and applies the **Large File Protocol** to extract, structure, and render that material into a single self-contained HTML wiki file.

- **Source of knowledge:** The updates file exclusively. No external knowledge or training data may be injected.
- **HTML output format:** A single portable `.html` file with all CSS inlined. No external dependencies, no separate assets, no JavaScript required for rendering.

## How It Works

### [AI INSTRUCTION] Before executing any step, you MUST read `.agents/protocols/large_files_protocol.md` in full.

1. **Receive** — An updates file arrives (source content about data engineering).
2. **Process (Large File Protocol Phases 0-4):**
   - Phase 0: Structural Reconnaissance — reading plan, line count, format identification
   - Phase 1: Spine Pass — sequential chunk-by-chunk structural map in `de_wiki/spine.md`
   - Phase 2: Deep Extraction — wiki topic files generated in `de_wiki/topics/`
   - Phase 3: Cross-Reference Synthesis & Contradiction Resolution — links verified, contradictions resolved in `de_wiki/contradictions.md`
   - Phase 4: Output Mapping & Master Synthesis — `de_wiki/output_map.md` and `de_wiki/master_summary.md`
3. **[POST-PROTOCOL] Render (Phase 5)** — Once the protocol's Phase 4 Gate is passed, render the completed wiki from `de_wiki/` into `output/option_a/index.html` using the HTML/CSS generation skill. This phase is NOT part of the Large File Protocol — it is a separate rendering step that runs after the protocol completes.

## Deliverables

- `de_wiki/` — Structured wiki markdown files (generated by the Large File Protocol during Phases 0-4)
- `output/option_a/index.html` — Single self-contained HTML wiki (rendered from `de_wiki/` markdown in Phase 5; all CSS inlined, no external dependencies)

## Core Constraint

The Large File Protocol (`.agents/protocols/large_files_protocol.md`) is the non-negotiable processing engine. Every phase gate must be satisfied before proceeding. No phase may be skipped, and no gate may be bypassed.

## Initialization Prompt

An initialization prompt template uses XML injection tags to assemble a single prompt file from source documents. The template is processed by `file_injector.py` (in this directory). When any source document is updated, re-run the injector to regenerate the initialization prompt.

### Template format (XML injection pattern)

```xml
<brain>

<file_system_path>brain.md</file_system_path>

<file_content>
</file_content>

</brain>
```

### Required sections (all must be injected)

| Section tag | Source file | Reason |
|---|---|---|
| `<brain>` | `brain.md` | Critical thinking module — mandatory for all sessions |
| `<aim>` | `aim.md` | This file — project scope (note: the Initialization Prompt metadata section below is documentation only and is stripped when injecting) |
| `<agents>` | `.agents/AGENTS.md` | Protocol and skill catalog |
| `<large_files_protocol>` | `.agents/protocols/large_files_protocol.md` | Core processing engine — always mandatory |
| `<html_css_generation>` | `.agents/skills/html_css_generation/SKILL.md` | Mandatory for Phase 5 rendering |
| *(add as needed)* | Additional protocols/skills | Include only if the specific updates file's processing requires them — consult AGENTS.md for the full catalog |

### Regeneration command

After editing any source file above, run from the project root:

```
python file_injector.py --template initialization_prompt_template.md --output initialization_prompt.md
```
