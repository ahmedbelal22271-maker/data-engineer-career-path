# Data Engineering Certification Roadmap

Based on José Siles' "2026 Data Professional Certification Matrix." Pursue certifications after completing the relevant IBM courses — certifications without hands-on experience rarely land jobs. Complete at minimum 2 project checkpoints in the platform before attempting its certification exam.

## Azure Track

| Cert | Role | Prerequisites |
|------|------|---------------|
| DP-900: Azure Data Fundamentals | All roles (entry) | Course 12, Course 9 |
| PL-300: Power BI Data Analyst Associate | Data Analyst | Course 10 |
| DP-700: Fabric Data Engineer Associate | Data Engineer | Course 8, Course 9 |
| DP-100: Azure Data Scientist Associate | Data Scientist | Course 13, Course 15 |
| AI-102: Azure AI Engineer Associate | AI Engineer | Course 15 |

## AWS Track

| Cert | Role | Prerequisites |
|------|------|---------------|
| DEA-C01: AWS Certified Data Engineer – Associate | Data Engineer | Courses 8, 9, 11, 12 |
| MLA-C01: AWS ML Engineer – Associate | ML Engineer | Course 13, Course 15 |
| MLS-C01: AWS ML Specialty | Data Scientist | Course 13, Course 15 |

## Google Cloud Track

| Cert | Role | Prerequisites |
|------|------|---------------|
| Google Cloud Data Analytics Certificate | Data Analyst | Enhancement A, Course 10 |
| Professional Data Engineer | Data Engineer | Courses 8, 9, 11, 12 |
| Professional Machine Learning Engineer | ML Engineer | Course 13, Course 15 |

## Snowflake Track

| Cert | Role | Prerequisites |
|------|------|---------------|
| SnowPro Core | All DE/DS/DA roles | Course 9 |
| SnowPro Advanced: Data Engineer | Data Engineer | Course 9 + Enhancement C |
| SnowPro Advanced: Data Analyst | Data Analyst | Course 9 + Course 10 |
| SnowPro Advanced: Data Scientist | Data Scientist | Course 13 + Course 9 |

Prep: Snowflake University (free trial + free badge courses).

## Databricks Track

| Cert | Role | Prerequisites |
|------|------|---------------|
| Data Analyst Associate | Data Analyst | Enhancement A + Courses 10, 12, 13 + Course 9 |
| Data Engineer Associate | Data Engineer | Courses 8, 11, 12 + Course 9 |
| Data Engineer Professional | Senior DE | All above + Course 8 |
| ML Associate | ML Engineer | Course 13 + Course 15 |
| ML Professional | Senior ML | Course 13 + Course 15 (deep) |

Prep: Databricks Academy free resources + Databricks Community Edition.

## Key Guidance

- Certifications without hands-on project experience rarely improve job prospects — each exam should be preceded by building in the platform
- Most cloud certs renew every 1–3 years; budget time for recertification
- Stacking vendor-neutral (SnowPro, Databricks) with one cloud platform is a common strategy
