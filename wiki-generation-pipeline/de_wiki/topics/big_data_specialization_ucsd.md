# Big Data Specialization — UC San Diego

A Coursera specialization covering big data concepts, tools, and applications across 6 courses (~104 hours).

## Courses

| # | Course | Hours | Focus |
|---|--------|-------|-------|
| 1 | Introduction to Big Data | 18 | What makes data "big", the V's, data science process, Hadoop ecosystem, MapReduce |
| 2 | Big Data Modeling and Management Systems | 15 | Data genres, management tools, AsterixDB, Vertica, Impala, Neo4j, Redis, SparkSQL |
| 3 | Big Data Integration and Processing | 17 | Data retrieval, integration patterns, Hadoop/Spark processing |
| 4 | Machine Learning With Big Data | 20 | ML process, exploratory analysis, model construction on Spark |
| 5 | Graph Analytics for Big Data | 12 | Graph-structured data, network analysis, scalable graph analytics |
| 6 | Big Data — Capstone Project | 22 | End-to-end big data ecosystem building |

## Course 1: Introduction to Big Data — Full Index

| Module | Topic | Key Items |
|--------|-------|-----------|
| 1 | Welcome — Getting to Know Us | Course overview, SDSC video |
| 2 | Big Data: Why and Where | Big Data era origins, applications (healthcare, sentiment analysis), machine-generated data, human-generated unstructured data, organization-generated siloed data, integrating diverse data |
| 3 | Characteristics of Big Data (The V's) | Volume, Variety, Velocity, Veracity, Valence, Value |
| 4 | Data Science: Getting Value | Big Data strategy, Five Components of Data Science, 5-step process (Acquire → Explore → Pre-process → Analyze → Communicate → Act) |
| 5 | Foundations for Big Data Systems | Distributed file systems, scalable computing, programming models |
| 6 | Getting Started with Hadoop | Hadoop ecosystem, HDFS, YARN, MapReduce, cloud computing, hands-on with Docker |
