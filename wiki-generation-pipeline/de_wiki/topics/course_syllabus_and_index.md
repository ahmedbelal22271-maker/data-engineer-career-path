# Course Syllabus and Module Index

The IBM Data Engineering Professional Certificate consists of 10 modules covering the full data engineering lifecycle. This page documents all 10 modules with their full syllabi, plus the Module 1 detailed content map.

## Course Overview

Data is growing at an unprecedented rate. How much value we derive from data depends on the accuracy of data and the efficiency with which we access it — that, in a nutshell, is the job of a Data Engineer. The Dice Tech Job Report of 2020 lists data engineering as the fastest-growing tech occupation with year-over-year growth of 50%.

**Instructors:** Rav Ahuja (IBM Skills Network), Amber Crooks (Lead Database Engineer, IBM alum), Ramesh Sannareddy (CEO, Mongo Factory), Xiao Yang (Data Engineer, Coursera), Ragu Cherukuru (Lead DBA, large retailer).

## Module 1: Modern Data Ecosystem and Role of Data Engineering

**Learning objectives:**
- Recall the different entities that form a modern data ecosystem
- Describe and differentiate the roles of Data Engineers, Data Scientists, Data Analysts, Business Analysts, and BI Analysts
- Explain what Data Engineering is
- List the tasks in a typical data engineering lifecycle
- Identify essential skills and qualities for data engineering
- Summarize how Data Engineering has evolved
- Discuss responsibilities and skillsets of a Data Engineer
- Recall how data professionals define data engineering and differentiate it from data analysis and data science
- Describe a day in the life of a Data Engineer

**Content:** Introduction to Data Engineering, Modern Data Ecosystem, Data Roles, Specializations, Scope of Data Engineering, Defining Data Engineering, Evolution of Data Engineering, Practice Quiz, Graded Quiz.

## Module 2: The Data Ecosystem and Languages for Data Professionals

**Content:** Overview of the Data Engineering Ecosystem (4min), Types of Data (4min), Understanding Different Types of File Formats (4min), Sources of Data (7min), Languages for Data Professionals (8min), Viewpoints: Working with Varied Data Sources and Types (6min), Metadata and Metadata Management (10min), Summary and Highlights (10min), Practice Quiz, Graded Quiz.

## Module 3: Responsibilities and Skillsets of a Data Engineer *(collected)*

**Content:** Overview of the Data Engineering Ecosystem (4min), Types of Data (4min), File Formats (4min), Sources of Data (7min), Languages for Data Professionals (8min), Viewpoints: Working with Varied Data Sources (6min), Metadata and Metadata Management (10min), Summary and Highlights, Practice Quiz, Graded Quiz.

## Module 4: Data Repositories, Data Pipelines, and Data Integration Platforms

**Content:** Overview of Data Repositories (4min), RDBMS (7min), NoSQL (7min), Data Warehouses/Marts/Lakes (7min), Optional: Data Lakehouses (8min), Viewpoints: Choice of Data Repository (6min), ETL/ELT and Data Pipelines (6min), Data Integration Platforms (4min), Viewpoints: Tools and Databases of Choice (6min), Summary and Highlights, Practice Quiz, Graded Quiz. Optional labs: IBM Db2 database, Cloud account, Db2 Lite.

## Module 5: Big Data Platforms

**Content:** Foundations of Big Data (5min), Big Data Processing Tools: Hadoop, HDFS, Hive, and Spark (6min), Viewpoints: Impact of Big Data (3min), Summary and Highlights, Practice Quiz, Graded Quiz.

## Module 6: Data Platforms, Data Stores, and Security

**Content:** Architecting the Data Platform (7min), Factors for Selecting Data Stores (6min), Security (6min), Viewpoints: Importance of Data Security (4min), Summary and Highlights, Practice Quiz, Graded Quiz.

## Module 7: Data Collection and Data Wrangling

**Content:** How to Gather and Import Data (6min), Data Wrangling (7min), Tools for Data Wrangling (5min), Lab: Load data into Datasette from CSV (15min), Optional Lab: Load data into Db2 from CSV (15min), Summary and Highlights, Practice Quiz, Graded Quiz.

## Module 8: Querying Data, Performance Tuning, and Troubleshooting

**Content:** Querying and Analyzing Data (5min), Performance Tuning and Troubleshooting (7min), Lab: Explore dataset using SQL queries in Datasette (15min), Optional Lab: Explore dataset using SQL in Db2 (15min), Summary and Highlights, Practice Quiz, Graded Quiz.

## Module 9: Governance and Compliance

**Content:** Governance and Compliance (7min), Summary and Highlights, Practice Quiz, Graded Quiz. Optional: Overview of the DataOps Methodology (10min).

## Module 10: Career Opportunities and Learning Paths

**Content:** Career Opportunities (5min), Data Warehousing Specialist (15min), Data Manager (10min), Viewpoints: Get into Data Engineering (7min), Learning Path (3min), Viewpoints: What Employers Look For (6min), Viewpoints: Many Paths to Data Engineering (5min), Viewpoints: Advice to Aspiring Data Engineers (6min), Summary and Highlights, Practice Quiz, Graded Quiz.

## Final Assignment

- Final Quiz (50min)
- Final Project Submission Guidelines (2min)
- AI-Graded Final Submission and Evaluation (20min)

## Course Wrap-Up

Congratulations and next steps (2min).
