# Data Engineering Career Ladder

Based on Sumit Gupta's "Data Engineering" infographic (2025), mapped to the IBM Data Engineering Professional Certificate plan.

| Level | Core Skills | IBM Course Coverage |
|-------|-------------|---------------------|
| **Beginner** | SQL, Python, Linux, Databases | Courses 1–7 |
| **Junior** | ETL/ELT, Data Warehousing, APIs, Git, Scheduling | Courses 8–9 |
| **Mid-Level** | Airflow, dbt, Spark/Kafka, Cloud Storage, Data Modeling | Courses 8, 12 + Enhancement C |
| **Senior** | Distributed Systems, Cloud Architecture, Streaming, Governance, Optimization | Courses 11–12 + Enhancements A–B |
| **Modern AI-Ready** | Vector DBs, RAG Pipelines, Feature Stores, LLM Data Workflows, Data Quality | Course 15 |

Each level builds on the previous one. The foundational skills (SQL, Python, Linux) are prerequisites for advancement. Mid-level and above requires both depth in at least one specialization and breadth across the full stack.

---

## Minimum Viable Path (MVP) — ~192h Fast-Track

A curated subset of the IBM Data Engineering Professional Certificate designed for career-switchers or bootcamp graduates targeting a junior DE role without committing to the full ~750h plan. Follow IBM courses in order, skip supplements except the one marked per course.

### MVP Course Sequence

| # | Course | Hours | Core Supplement |
|---|---|---|---|
| 1 | Introduction to Data Engineering | 14h | AWS "What Is Big Data?" explainer |
| 2 | Python for Data Science, AI & Development | 24h | Real Python (file I/O, requests, pandas) |
| 3 | Python Project for Data Engineering | 10h | *(self-contained)* |
| 4 | Introduction to Relational Databases | 16h | PostgreSQL official tutorial (DDL/DML) |
| 5 | Databases and SQL for Data Science with Python | 18h | Mode SQL Tutorial (Basic + Intermediate) |
| 6 | Linux Commands and Shell Scripting | 17h | Linux Journey (command line + permissions) |
| 8 | ETL and Data Pipelines with Shell, Airflow and Kafka | 18h | Confluent Developer "Kafka 101" (first 4 modules) |
| 9 | Getting Started with Data Warehousing and BI Analytics | 10h | dbt Learn "Fundamentals" course |
| 12 | Introduction to Big Data with Spark and Hadoop | 20h | freeCodeCamp PySpark Tutorial |
| 14 | Data Engineering Capstone Project | 18h | *(self-contained)* |

### What the MVP covers and omits

| Covered | Skipped (return later) |
|---|---|
| Python scripting for data tasks | DBA & security depth (Course 7, Enhancement B) |
| SQL — querying, joins, views, stored procedures | NoSQL databases (Course 11) |
| Linux, Bash, cron scheduling | ML with Spark (Course 13) |
| ETL pipelines with Airflow + Kafka basics | GenAI / RAG pipelines (Course 15) |
| Data warehousing concepts + dbt intro | Hive/Impala/Pig (Enhancement A) |
| Hadoop + Spark fundamentals | Data governance (Ranger/Atlas, Enhancement B) |
| End-to-end capstone project | Advanced dbt, data contracts (Enhancement C) |

### After the MVP

1. Apply for junior DE roles immediately — these skills match typical requirements.
2. Return to skipped courses (7, 10, 11, 13) based on target job description.
3. Add Course 15 (GenAI) if targeting LLM-driven data pipeline roles.
4. Work through Enhancements A–C once on the job and context is clear.
