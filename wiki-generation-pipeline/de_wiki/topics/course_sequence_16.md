# IBM Data Engineering Professional Certificate — 16-Course Sequence

The IBM Data Engineering Professional Certificate forms the primary spine of the learning path. Courses are listed in official order.

## Foundation Courses (1–7)

### Course 1: Introduction to Data Engineering (~14h)
DE lifecycle, data repositories, data pipelines, Big Data engines, data security, governance, and compliance. Entry-level orientation to the field.

### Course 2: Python for Data Science, AI & Development (~24h)
Python syntax, data types, data structures, pandas, NumPy, REST APIs, web scraping with BeautifulSoup.

### Course 3: Python Project for Data Engineering (~10h)
Hands-on ETL project: webscraping + API extraction + data transformation using Python and Jupyter. Self-contained — no supplements needed.

### Course 4: Introduction to Relational Databases (RDBMS) (~16h)
Data models, ER diagrams, relational schemas, MySQL, PostgreSQL, IBM DB2.

### Course 5: Databases and SQL for Data Science with Python (~18h)
SQL DDL/DML, joins, views, stored procedures, transactions, Jupyter integration.

### Course 6: Hands-on Introduction to Linux Commands and Shell Scripting (~17h)
Linux architecture, Bash shell, file management, scripting, cron jobs, networking.

### Course 7: Relational Database Administration (DBA) (~21h)
Backup/restore, user roles and permissions, performance monitoring, troubleshooting, automation.

## Core DE Courses (8–11)

### Course 8: ETL and Data Pipelines with Shell, Airflow and Kafka (~18h)
ETL vs ELT patterns, batch vs concurrent execution, Bash/Python ETL workflows, Apache Airflow DAGs, Apache Kafka streaming pipelines, data pipeline components.

### Course 9: Data Warehouse Fundamentals (~16h)
Data warehouse design and population, CUBE/ROLLUP/materialized views, star and snowflake schemas, IBM Cognos Analytics dashboards.

### Course 10: BI Dashboards with IBM Cognos Analytics and Google Looker (~12h)
IBM Cognos Analytics, Google Looker Studio, interactive dashboards, data visualization best practices.

### Course 11: Introduction to NoSQL Databases (~18h)
Four NoSQL categories, MongoDB CRUD, Cassandra keyspace/table operations, IBM Cloudant.

## Advanced Courses (12–16)

### Course 12: Introduction to Big Data with Spark and Hadoop (~20h)
Hadoop architecture, HDFS, Hive, HBase, Spark fundamentals, RDDs, DataFrames, SparkSQL, Docker/Kubernetes deployment.

### Course 13: Machine Learning with Apache Spark (~16h)
ML role in data engineering, Spark ML pipelines, regression, classification, clustering with SparkML, generative AI concepts, model persistence.

### Course 14: Data Engineering Capstone Project (~18h)
End-to-end project integrating RDBMS, NoSQL (MongoDB), Apache Spark, data warehousing, ETL pipelines, and BI dashboards.

### Course 15: Generative AI: Elevate your Data Engineering Career (~13h)
GenAI for data generation, augmentation, anonymization, ETL processes, warehouse schema design, and infrastructure setup. Practical labs with real-world case studies.

### Course 16: Data Engineering Career Guide and Interview Preparation (~11h)
Role of a data engineer, career paths, job search strategies, resume/portfolio building, interview types, mock interviews, professional presentation.
