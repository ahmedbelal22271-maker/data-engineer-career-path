# Modern Data Ecosystem

> Quote from Forbes 2020 report on data in the coming decade:
> "The constant increase in data processing speeds and bandwidth, the nonstop invention of new tools for creating, sharing, and consuming data, and the steady addition of new data creators and consumers around the world, ensure that data growth continues unabated. Data begets more data in a constant virtuous cycle."

## Overview

A modern data ecosystem includes a whole network of interconnected, independent, and continually evolving entities:

- Data that has to be integrated from disparate sources
- Different types of analysis and skills to generate insights
- Active stakeholders to collaborate and act on insights generated
- Tools, applications, and infrastructure to store, process, and disseminate data as required

## Data Sources

Data is available in a variety of structured and unstructured datasets:

- Text
- Images
- Videos
- Clickstreams
- User conversations
- Social media platforms
- Internet of Things (IoT) devices
- Real-time events that stream data
- Legacy databases
- Data sourced from professional data providers and agencies

## Stages of Data Processing

### Stage 1: Data Acquisition
Pull a copy of the data from original sources into a data repository. Key concerns:
- Working with data formats, sources, and interfaces
- Reliability, security, and integrity of data being acquired

### Stage 2: Data Organization and Cleansing
Raw data gets organized, cleaned up, and optimized for access:
- Conform to compliance and standards (e.g., regulations on personal data like health, biometrics, household data from IoT)
- Adhere to master data tables for standardization across all applications and systems
- Key challenges: data management, working with repositories providing high availability, flexibility, accessibility, security

### Stage 3: Data Access and Consumption
Business stakeholders, applications, programmers, analysts, and data science use cases pull data:
- Data Analysts may need raw data
- Business stakeholders may need reports and dashboards
- Applications may need custom APIs
- Key challenges: interfaces, APIs, applications tailored to specific user needs

## Emerging Technologies Shaping the Data Ecosystem

- **Cloud Computing** — limitless storage, high-performance computing, open source technologies, ML tools
- **Machine Learning** — Data Scientists create predictive models by training ML algorithms on past data
- **Big Data** — datasets so massive and varied that traditional tools are inadequate, paving way for new tools, techniques, and insights
