# Scope of Data Engineering

## Core Definition

> Data Engineering concerns itself with the mechanics for the flow and access of data. Its goal is to make quality data available for fact-finding and data-driven decision making.

## Key Task Areas

### 1. Collecting Source Data
Extracting, integrating, and organizing data from disparate sources.
- Develop tools, workflows, and processes to acquire data from multiple sources
- Design, build, and maintain scalable data architecture to store data (databases, warehouses, data lakes, etc.)

### 2. Processing Data
Cleaning, transforming, and preparing data so that it is usable.
- Implement and maintain distributed systems for large-scale processing
- Design ETL pipelines for extraction, transformation, and loading into data repositories
- Design/implement solutions for validating and safeguarding quality, privacy, and security
- Optimize tools, systems, and workflows for performance, reliability, scalability
- Ensure data meets all regulatory and compliance guidelines

### 3. Storing Data
Reliable and easy availability of data.
- Architect or implement data stores for processed data
- Ensure systems are scalable (evolving data and business needs)
- Ensure tools/systems for data privacy, security, compliance, monitoring, backup, and recovery

### 4. Making Data Available to Users Securely
- APIs, services, and programs that retrieve data on defined parameters
- Interfaces and dashboards that present data for users to derive insights
- Right measures and checks for secure, rights-based access

## Key Insight: Data Engineering is a Team Sport

No one person is expected to have all the knowledge, skills, and specializations required. Different aspects require different expertise:
- **Architect skills** — for designing data management systems
- **Database expertise** — for ensuring data stores are available and optimized
- **Programming languages, distributed systems, database tools** — all part of data engineering, but may require different skill sets
