# (Optional) Labs: IBM Cloud and IBM Db2

## Overview

**IBM Db2** is a popular relational database from IBM used for both **OLTP** (Online Transaction Processing) and **Data Warehousing** workloads. These optional labs walk through setting up a free instance of Db2 Lite on IBM Cloud.

## Why Db2?

IBM Db2 is a production-grade RDBMS that supports:

- **OLTP workloads** — high-frequency transactional operations with fast read/write performance
- **Data Warehousing (OLAP)** — complex analytical queries over large historical datasets

The Db2 Lite plan on IBM Cloud provides a free, fully functional instance suitable for learning and experimentation without requiring payment credentials.
