# Responsibilities and Skillsets of a Data Engineer — Summary and Highlights

## Role Responsibilities

A Data Engineer is responsible for:

- Gathering data from disparate sources
- Integrating data into a unified view for data consumers
- Preparing data for analytics and reporting
- Managing data pipelines for a continuous flow of data from source to destination systems
- Managing the complete infrastructure for the collection, processing, and storage of data

## Skillsets

To be successful in their role, Data Engineers need a mix of **technical**, **functional**, and **soft skills**.

### Technical Skills
- Working with different operating systems and infrastructure components such as virtual machines, networks, and application services
- Working with databases and data warehouses, data pipelines, ETL tools, and big data processing tools
- Proficiency in languages for querying, manipulating, and processing data

### Functional Skills
- Understanding the potential application of data in business contexts
- Converting business requirements into technical specifications
- Understanding the software development lifecycle (SDLC)
- Knowledge of data quality, privacy, security, and governance

### Soft Skills
- Interpersonal skills
- Ability to work collaboratively and as part of a team
- Effective communication
