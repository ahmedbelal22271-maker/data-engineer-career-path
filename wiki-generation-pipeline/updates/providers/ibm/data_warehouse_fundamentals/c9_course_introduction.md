# Course Introduction

High-quality data, when analyzed over time, helps users make smarter and more informed decisions. Data warehouses play a significant role in making this possible. A data warehouse is a large repository of data where the data is organized and optimized for analysis and reporting.

## Who This Course Is For

This hands-on IBM course is designed for data professionals who want to skill up or start a new career in data management or business intelligence. Whether you're a data engineer developing data platforms, a data warehousing specialist designing schema structures, or a BI analyst using data for advanced analytics, this course will help you excel. It is also suitable for many other data professionals, including data architects, data managers, data analysts, and data scientists.

## Course Structure

The course has three modules. Each module is designed to be completed in 2-4 hours. However, this is a self-paced course, and you can complete it in a time frame that suits your needs. But we recommend setting deadlines for yourself.

## What You'll Learn

In this course, you'll learn about data warehouses, data marts, and data lakes by exploring them based on their architecture, features, and advantages. You will develop skills to identify why organizations select a specific data warehouse platform, how to design data warehouses, model the data using star and snowflake schemas, and query the warehouse by utilizing cube, rollup, and materialized views. You will learn practical skills by completing numerous hands-on labs and a final project.

## Hands-On Experience

You will perform various data warehousing tasks, such as designing the database, populating staging environments, loading the warehouse, and querying the warehouse using SQL. You will work with popular databases such as PostgreSQL, MySQL, and IBM Db2.

## Prerequisites

To succeed in this course, you should have a fundamental knowledge of relational database management systems and a working knowledge of SQL.

## Course Tips

To get the most from this course, watch each video, review all the readings, complete all hands-on labs, check your learning with practice in graded quizzes and complete your final project.
