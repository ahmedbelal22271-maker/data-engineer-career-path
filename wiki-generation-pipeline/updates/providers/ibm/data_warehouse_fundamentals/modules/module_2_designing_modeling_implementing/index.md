> **Course 9:** Data Warehouse Fundamentals

# Module 2: Designing, Modeling, and Implementing Data Warehouses

## Overview
This module explores general and reference enterprise data warehousing architecture. You'll discover how data cubes relate to star schemas, learn about materialized views, facts and dimensions, snowflake schemas, and staging.
