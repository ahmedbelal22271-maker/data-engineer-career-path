> **Course 9:** Data Warehouse Fundamentals

# Data Warehouse Fundamentals

## Course Information
- **Provider:** IBM
- **Platform:** Coursera
- **Instructor:** Rav Ahuja
- **Duration:** 2 weeks (15 hours total)
- **Level:** Intermediate
- **Prerequisites:** Fundamental knowledge of relational database management systems and working knowledge of SQL

## Course Description
This hands-on IBM course is designed for data professionals who want to skill up or start a new career in data management or business intelligence. You'll learn about data warehouses, data marts, and data lakes, how to design data warehouses, model data using star and snowflake schemas, and query warehouses using cube, rollup, and materialized views.

## What You'll Learn
- Data warehouse architecture, features, and advantages
- Data marts and data lakes
- Star and snowflake schema design
- Cubes, rollups, and materialized views
- Staging environments and data quality
- Working with PostgreSQL, MySQL, and IBM Db2
