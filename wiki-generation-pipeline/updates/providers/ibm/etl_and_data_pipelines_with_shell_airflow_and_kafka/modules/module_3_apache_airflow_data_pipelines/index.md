# Module 3: Apache Airflow Data Pipelines

## Module Overview
- **Duration**: ~3.4h (203 minutes total pure content time)
- **Objectives**:
  - Build data pipelines utilizing Airflow.
  - Recall DAG (Directed Acyclic Graph) components.
  - Outline Airflow's architecture and its primary components.
  - Develop a DAG utilizing Airflow.
